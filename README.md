# Flutter Parallax Scrolling Effect

A Flutter UI experiment demonstrating a parallax scrolling effect, designed in Figma.

## Tech stack

- Flutter
- Dart

## Run locally

1. Install the Flutter SDK.
2. Clone this repository:
   `git clone https://github.com/khalid-alsaleh-dev/FlutterParallexScrollingEffect.git`
3. Install dependencies and launch:
   `cd FlutterParallexScrollingEffect`
   `flutter pub get`
   `flutter run`
